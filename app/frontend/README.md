Vite + React + TypeScript frontend scaffold for Investments UI.

Run locally:

```bash
cd app/frontend
npm install
npm run dev
```

Notes:
- Development dev server serves on `http://localhost:5173` by default.
- In production, set `API_URL` (or configure rewrites) to your backend endpoint.
- For Vercel: point the project root to `app/frontend` when creating the Vercel project for monorepo support.
